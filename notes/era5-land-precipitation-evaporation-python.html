ERA5-Land 降水与实际蒸散：从自动下载到流域水量平衡

Copernicus CDS API、2006–2022 年逐日数据、GNSS 多边形裁剪、NetCDF 输出与 MATLAB 对接

Chistrong Wen · 2026-11-04 · Data & Methods · 中文
← 返回 Research Notes
核心目标：用 Python/Spyder 自动下载美国西部 GNSS 反演区域内的 ERA5-Land 降水 P 和 实际蒸散 ET，以 mm/day 输出，之后结合 GNSS 反演总水储量 S，通过 R = P − ET − dS/dt 估算径流，并使用独立的 GRDC 记录验证。下载范围先用外接矩形，下载后才使用黑色边界多边形掩膜。

1. 数据产品与研究用途

ERA5-Land 是 ECMWF 陆面再分析产品。本文下载 total_precipitation（总降水）和 total_evaporation（净地表蒸散），取 ERA5-Land 的 00:00 UTC 累计值，将其归入前一个 UTC 日；经源单位 m 转换为 mm/day。ERA5-Land 约 9 km 的原生水平分辨率不同于下载网格的坐标间隔；不能把插值网格误认为独立的高分辨率观测。

输出原始变量处理单位
Ptp日累计值 × 1000mm/day
ETe日累计值 × (−1000)mm/day
Inside_GNSS区域矢量格点中心位于多边形内=1无量纲

ERA5-Land 的蒸散符号约定为从地表向大气蒸散时原始值为负；取负后正数表示蒸散损失，负数可以表示凝结。不要把所有负 ET 强行设置为零；也不要把潜在蒸散误当作实际蒸散。

dS/dt = P − ET − R [忽略或单独处理其他跨界水通量] R = P − ET − dS/dt S: GNSS-derived TWS [mm EWH] P, ET, R: basin-mean [mm/day]

2. 研究区域及项目目录

本文实例统一使用 USA_border_L1.txt，前两列为经度、纬度，覆盖美国西部 GNSS 反演的黑色研究区。示例时段固定为 2006-01-01 至 2022-12-31，文件存于 westUS_discharge/ 下。

│   └── daily_masked/         # 逐日 mm/day + 多边形掩膜

空间尺度提醒：多边形掩膜仅按ERA5-Land网格中心判断是否属于 GNSS 区域。后续对小流域统计P/ET，最好依据流域与气象格网交叠面积进行加权；单纯用网格中心判断可能使小流域没有入选格点。

3. Spyder / Anaconda 环境安装

在 Spyder 的 IPython Console（不是 .py 脚本编辑器）查看解释器，安装依赖：

import sys
print(sys.executable)
%pip install cdsapi xarray netCDF4 numpy pandas matplotlib

安装完成后重启 Kernel，检查：

import cdsapi, xarray, netCDF4, numpy, pandas, matplotlib
print("All dependencies are available.")

如果使用 conda install cdsapi 提示 PackagesNotFoundError 且只有 defaults 通道，可优先使用上面的 %pip，或在终端使用 conda install -c conda-forge cdsapi。确保安装位置与 Spyder 当前解释器相同。

4. CDS API 密钥配置（macOS）

先登录 Copernicus Climate Data Store，从账户页面获取 Personal Access Token，并在 ERA5-Land 数据集页面接受许可条款。

若报 Missing/incomplete configuration file: /Users/.../.cdsapirc，在 Spyder Console 执行以下代码（密钥仅写入本地，不应上传GitHub）：

from pathlib import Path
import getpass, os
cfg = Path.home() / ".cdsapirc"
key = getpass.getpass("CDS Personal Access Token: ").strip()
cfg.write_text("url: https://cds.climate.copernicus.eu/api\n"
               f"key: {key}\n")
os.chmod(cfg, 0o600)
print("CDS configuration written:", cfg)

随后测试 client = cdsapi.Client()；客户端成功初始化不代表已获下载权限，仍需真实提交请求确认。

5. Python 批量下载和掩膜：P07

使用 P07_download_ERA5Land_P_ET.py 完成两阶段流程：CDS 年度下载 → 按前一UTC日归属、单位转换、GNSS多边形掩膜和NetCDF输出。下载请求包含年、月、日、00:00 UTC、变量名和经纬度外接矩形。该程序输出约定与下游 MATLAB P08 一致。

下载核心请求（此段为P07的关键逻辑摘录；完整源代码应使用项目的 P07_download_ERA5Land_P_ET.py）：

import cdsapi
client = cdsapi.Client()
request = {
    "variable": ["total_precipitation", "total_evaporation"],
    "year": "2006",
    "month": [f"{m:02d}" for m in range(1, 13)],
    "day": [f"{d:02d}" for d in range(1, 32)],
    "time": ["00:00"],
    "area": [NORTH, WEST, SOUTH, EAST],
    "data_format": "netcdf",
    "download_format": "unarchived",
}
client.retrieve("reanalysis-era5-land", request,
                "era5land_00utc_2006.nc")

实际批处理程序读取 USA_border_L1.txt 计算 [N,W,S,E]，按年度保存文件，自动跳过已下载的年度文件，并单独补充结束年份下一年1月1日00 UTC 的记录，以覆盖最后一天。若首次试运行，推荐先选小时间范围，避免盲目发起大体积请求。

为什么时间要减一天？当下载 2006-01-02 00:00 UTC 的累计降水时，该时刻的累计值通常代表 2006-01-01 的一天。因此处理年 Y 的资料需要同时拥有 Y+1 年 1 月 1 日 00 UTC 的记录。

# DataArray 的 UTC 时间标签代表累计结束时刻
target_day = valid_time - pandas.Timedelta(days=1)
P_mm_day  = tp * 1000.0
ET_mm_day = -e * 1000.0
# (lat, lon) 网格中心套用 GNSS 多边形掩膜
P_masked  = P_mm_day.where(inside_gnss)
ET_masked = ET_mm_day.where(inside_gnss)

在 Spyder 中设置工作目录为 westUS_discharge，点击 F5 执行脚本；或在终端执行：

python P07_download_ERA5Land_P_ET.py \
  --border USA_border_L1.txt \
  --out P07_ERA5Land_P_ET \
  --start-year 2006 --end-year 2022
断点继续：已存在的年度源文件会被跳过，处理结果单独保存。若某年度源文件损坏或下载不完整，请删除该年度文件后重新请求；不能仅依据文件存在就认定内容完整。

6. 输出 NetCDF 与质量控制

处理后的每年文件应包含 lat、lon、time、P_mm_day、ET_mm_day、Inside_GNSS。2006 年应有365天，闰年366天。检查有效格点、范围、单位和日期是否连续。

import xarray as xr
fn = "P07_ERA5Land_P_ET/daily_masked/ERA5Land_P_ET_daily_2006.nc"
ds = xr.open_dataset(fn)
print(ds)
print(ds.time.values[0], ds.time.values[-1])
print(ds["P_mm_day"].attrs, ds["ET_mm_day"].attrs)
print("inside cells:", int(ds.Inside_GNSS.sum()))
print("P min/max:", float(ds.P_mm_day.min()), float(ds.P_mm_day.max()))
print("ET min/max:", float(ds.ET_mm_day.min()), float(ds.ET_mm_day.max()))
ds.close()

在 MATLAB 中核查尺寸和变量：

ncdisp('P07_ERA5Land_P_ET/daily_masked/ERA5Land_P_ET_daily_2006.nc')
lat = ncread(fn,'lat'); lon = ncread(fn,'lon');
[LAT,LON] = ndgrid(lat,lon); % 注意先纬度、后经度
% isinterior(Polygon,LON,LAT)，而不是反过来
必查事项：此前 P08 示例曾误写成 [LON,LAT]=ndgrid(la,lo)。正确写法是 [LAT,LON]=ndgrid(la,lo)，否则多边形检测将经纬度互换，可能造成没有气象格点入选。代码示例的 fn 必须先指定实际NetCDF路径。

7. 衔接 GNSS 水储量与 GRDC 径流

在每个完全位于黑色GNSS区域内且经前序筛选的流域中，从ERA5-Land网格提取面积加权的 P、ET，读取 GNSS TWS（mm EWH），再按统一日期计算30天水量平衡：

R̄_30(t) = { Σ_[t−29,t] (P − ET) − [ S(t) − S(t−30) ] } / 30 R̄_30: mm/day，S: mm EWH，P/ET: mm/day

用 Q_obs(mm/day)=86.4×Q_GRDC(m³/s)/A(km²) 与反演径流在完全相同的30天支持区间比较，并报告NSE、KGE、RMSE、Bias等。GNSS观测的日期是日初还是日末、ERA5-Land的UTC日界线，以及30天窗口的左右端点必须统一；不要把平滑后的估算径流称为独立的逐日径流。

水量平衡假定未列出的跨界地下水流、人工取水与调水等通量可忽略或已单独处理；GRDC仅用于独立验证，不参与计算。水量平衡产生的负径流应保留为诊断信号，不应自动截零。

8. 常见错误与研究限制

问题原因 / 正确处理
ModuleNotFoundError: cdsapi在 Spyder 实际使用的解释器中安装 %pip install cdsapi 并重启Kernel。
PackagesNotFoundErrorconda 的 defaults 通道不含此包；改用pip或conda-forge。
Missing/incomplete .cdsapirc本地配置 url 和 key，勿公开Token。
CDS 权限 / license 错误确认账号登录、使用条款接受、API配置有效。
lake3.kml 不存在这是其他KML脚本的文件路径错误；当前ERA5-Land处理使用 USA_border_L1.txt。
末日缺失或错年ERA5-Land 00 UTC 累计值归属前一天；最后一天需要下一年首日记录。
ET符号错误原始净蒸散 e 采用向下为正，实际蒸散损失常为负；输出ET使用 -e×1000。
流域气象格点为零小流域无格点中心；考虑网格-流域交叠面积权重，不要强制补零。
GNSS TWS与ERA5-Land分辨率不一致格点可对齐并不代表可独立分辨该小流域；还需GNSS空间恢复与泄漏敏感性评估。
