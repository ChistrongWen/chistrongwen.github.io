1. 为什么采用弹性半无限空间？

地震同震形变发生在相对短的时间尺度上。在一种常用的一阶近似中，地球表面附近的岩石被视作均匀、各向同性、线弹性半无限体：水平范围无限，地表为平面，深度方向无限延伸；介质的弹性性质由 Lamé 常数 λ、μ 或泊松比 ν 描述。这一近似能有效隔离断层滑移导致的瞬时弹性响应，但不包含真实地球的球形曲率、分层、黏弹性、地形与海水动力响应。[1,2]

z ≤ 0（地表 z = 0，向上为正） ∂σᵢⱼ / ∂xⱼ = 0 （静态平衡，无体力增量） σᵢⱼ = λ δᵢⱼ (∇·u) + μ(∂uᵢ/∂xⱼ + ∂uⱼ/∂xᵢ) μ∇²u + (λ + μ)∇(∇·u) = 0 σᵢⱼ nⱼ = 0, 在自由表面 z = 0

这里 u 为位移向量，σ 为应力张量。上述自由表面边界条件意味着模型顶面无外加表面牵引：因此标准Okada解不显式考虑海水载荷；在大洋中将其直接解释为真实海底形变时，应将这一点作为模型近似说明。

2. 断层位错：连续介质中的位移不连续

位错模型将地震断层表示为介质内部的一个有限矩形滑移面。其两侧位移出现有限跳变，而断层外介质仍满足弹性平衡方程。用断层面两侧的位移差表示位错：

[u] = u⁺ − u⁻ = U₁ ŝ + U₂ d̂ + U₃ n̂ U₁ = SLIP × cos(RAKE) （沿走向） U₂ = SLIP × sin(RAKE) （沿倾向） U₃ = OPEN （张裂方向）

ŝ、d̂、n̂ 分别为断层的走向、倾向、法向基向量；正负号需遵守具体实现的约定。逆冲、正断、走滑和张裂机制，均可由分量组合表示。地表有位移不代表断层必须出露地表：埋藏断层滑移同样能造成广域地表隆升或沉降。

3. Okada (1985) 的解析解如何工作？

Okada (1985) 将点源解积分到有限矩形断层，并给出半无限空间自由表面的闭式表达，分别处理沿走向剪切、沿倾向剪切和张裂三类位错。线弹性条件下三者可通过叠加原理组合。[1]

u(x) = U₁ · Gˢˢ(x; geometry,ν) + U₂ · Gᵈˢ(x; geometry,ν) + U₃ · Gᵗᶠ(x; geometry,ν) 对任一矩形核函数 F： C[F] = F(x,p) − F(x,p−W) − F(x−L,p) + F(x−L,p−W)

其中 L 为断层走向长度，W 为倾向宽度；四角组合通常称为 Chinnery notation，使有限矩形断层的位移核能够通过角点函数快速计算。这不是忽略四角以外的断层影响，而是对矩形面分布积分后的解析表达。[1]

本次上传的函数中，chinnery() 实现四角组合，而 ux_ss/ux_ds/ux_tf 等函数分别计算走滑、倾滑、张裂位移核；最后旋转回地理坐标系，输出东、北、上三维位移。相关代码保留了Okada (1985) 的解析公式，同时进行了MATLAB向量化。[3]

1985与1992的区别：Okada (1985) 重点给出地表变形的解析表达；Okada (1992) 扩展到弹性半空间内部变形。本文上传的 okada85.m 针对地表点计算，不能仅修改观测点的深度就将它当作完整的地下三维位移函数。如果目标是海底以下或任意埋深的内部位移，应使用适合Okada (1992) 的程序（如NIED的DC3D）并检验参数约定。[2,4]

4. okada85.m 的输入、输出及约定

上传源码中的函数原型是：

[uE,uN,uZ] = okada85(E,N,DEPTH,STRIKE,DIP,LENGTH,WIDTH,RAKE,SLIP,OPEN,NU);
参数含义与重要约定
E, N观测点相对断层中心水平投影的东、北坐标；通常以km为单位
DEPTH断层几何中心到地表的深度，向下为正
STRIKE走向角，正北起顺时针0–360°；沿走向观察，断层向右侧倾斜
DIP倾角，0–90°，相对水平面
LENGTH, WIDTH沿走向与沿倾向的断层尺寸，必须与E、N、DEPTH使用同一长度单位
RAKE滑动角，角度单位；沿走向剪切与倾向剪切由其分解
SLIP, OPEN断层滑动量和张裂量；位移输出继承其长度单位
NU泊松比；建议明确传入，例如 0.25；上传版本实际默认0.281
uE,uN,uZ地表东、北、上位移；uZ > 0 表示隆升

中心深度与上缘深度的转换是最常见的错误之一。对于一个沿倾向宽度为 W 的矩形断层，其几何中心和上缘深度满足：

depth_center = depth_top + 0.5 × W × sin(dip) depth_top = depth_center − 0.5 × W × sin(dip)

因此，若有限断层模型文件提供的是上边缘深度，必须先换算成中心深度后再调用。还需核对文件给出的经纬度究竟代表上缘中点、断层中心还是某个角点；只调整深度、不调整水平位置可能仍然出错。

5. 运行MATLAB：一个可复现的逆冲断层示例

将 okada85.m 与 okada85_demo.m 放在同一个文件夹；在MATLAB当前路径运行脚本。示例使用一个假设的矩形逆冲断层，不是2011年日本东北地震的真实滑移模型，不应将其示意结果作为观测或科学结论。

% 网格与几何长度均用 km；滑移与位移均用 m
[E,N] = meshgrid(-100:2:100,-100:2:100);
depth=12; strike=200; dip=15;
L=80; W=40; rake=90; slip=5; opening=0; nu=0.25;

% 断层上缘不得无意间穿出模型地表
assert(depth - W*sind(dip)/2 > 0);

[uE,uN,uZ] = okada85(E,N,depth,strike,dip, ...
                      L,W,rake,slip,opening,nu);

figure('Color','w');
imagesc(E(1,:),N(:,1),uZ);
axis xy equal tight; colorbar;
xlabel('East (km)'); ylabel('North (km)');
title('Coseismic vertical displacement (m)');
运行要点：显式传入 nu，仅请求三个输出时函数返回位移；如果请求其它数量的输出，函数的返回内容会改变。可以先运行原作者发布的 okada85_checklist.m 验证官方论文测试用例，再使用实际有限断层模型。[3]

6. 扩展到2011年东北日本地震：多子断层叠加

真实大型地震的滑动分布通常由数十至数百个子断层组成。在线弹性假设下，对每个子断层分别求解三维位移，再对所有子断层求和：

uₜₒₜₐₗ(x) = Σₖ uₖ(x) 区域平均同震垂直位移： <uZ> = Σᵢ Aᵢ Mᵢ uZᵢ / Σᵢ Aᵢ Mᵢ

其中 Aᵢ 为格点面积，Mᵢ 为研究区海洋掩膜。将经纬度转换为每个子断层局地东、北距离时，应注意大区域内球面距离和局地平面近似的误差；在远离断层的地点，也应评估平面弹性半空间假设的适用范围。

% 示例结构：faults需自行从已核验的有限断层文件解析
uZ_sum = zeros(size(E));
for k = 1:numel(faults)
    f = faults(k);
    % E_k,N_k: 每个格点相对第k子断层中心的东/北坐标(km)
    [~,~,dZ] = okada85(E_k,N_k,f.depth_center, ...
        f.strike,f.dip,f.length,f.width, ...
        f.rake,f.slip_m,0,0.25);
    uZ_sum = uZ_sum + dZ;
end

上段是计算逻辑示意，faults、E_k、N_k 不属于 okada85 内置变量，需要从滑移模型读取并构建；前面的单断层脚本才是无需外部震源数据的完整运行示例。

注意物理量：Okada得到的是地壳同震位移阶跃（m或mm），并不是天然的长期线性趋势（mm/yr），更不等同于地心海面变化。若要评估2005–2024年回归趋势中的阶跃影响，应在给定地震时刻构造Heaviside阶跃，并使用与目标序列相同的回归基函数估计等效趋势；该数值依赖拟合时段和阶跃是否单独建模。

7. 计算验证与常见错误

  • 上缘深度误当中心深度：会改变形变幅度及空间图案；先统一每个子断层的参考点。
  • 单位不一致：几何参数可统一为km，SLIP为m；输出位移为m，转换mm应乘1000，倾斜/应变的缩放要另行检查。
  • 错误泊松比：所上传函数头部标注0.25，实际代码默认0.281，应显式设置并报告。
  • 倾角和走向不一致：断层的向右倾斜约定、rake符号及不同模型文件的坐标定义必须逐项核实。
  • 忽略模型边界：标准Okada未考虑真实海水压力、地球分层、地形和曲率；应将此作为近似而非完整海洋响应。
  • 直接把海底位移当海面趋势：对于区域海平面预算，还需要质量—体积关系、海水密度及地心参考框架一致性。
  • 验证：使用原作者的checklist测试，与另一套独立实现比较，并检查网格加密后区域平均是否稳定。

8. 软件函数到底来自哪里？

三个层级必须分别引用：
① 理论：Okada (1985) 为半无限弹性空间的地表解析解；
② 软件：François Beauducel 为本次使用的MATLAB okada85.m 实现作者；
③ 断层参数：实际地震需要引用对应有限断层滑移模型的数据作者及版本，而不能只引用Okada。

上传版本信息：文件注明作者 François Beauducel（Institut de Physique du Globe de Paris），创建于1997年，最近注明更新为2014-05-24；授权条款为BSD类许可。代码在头部记录了若干数值与边界条件修复。用户上传的这一份含有不同于头部说明的泊松比默认值，故文章明确称之为“本地使用版本”，不直接声明它与网站下载的原始版本逐字相同。
