USGS 有限断层模型如何批量下载？

FDSN 地震目录、GeoJSON 事件详情、FSP 文件与可复现 MATLAB 数据流程

Chistrong Wen · 2026-11-02 · Data & Computational Workflow · 中文
← 返回 Research Notes
核心结论：USGS 地震目录提供地震事件的查询接口，但不是所有地震都具有有限断层 FSP 模型。推荐工作流是：① 按时间、震级和区域查询 ComCat → ② 根据每个事件的 GeoJSON detail 读取 finite-fault 产品 → ③ 从 contents 中识别并下载 .fsp → ④ 保存模型来源、版本及事件清单 → ⑤ 检查断层几何和单位后再用于 Okada 位错计算。

1. 下载的是什么？事件目录不等于断层滑移模型

地震目录一般提供事件发生时间、震中、震级和深度；有限断层模型（finite-fault model）还描述断层面的空间几何、各子断层的滑移量及滑移方向。后者是计算同震地表/海底位移的主要输入。USGS 对部分事件发布有限断层模型，其中包含 FSP（Finite Source Parameter）ASCII 格式文件，可与源模型元数据一起用于复现计算。

文件/数据物理内容主要用途
GeoJSON catalog震级、时间、震中、事件 ID、详情链接建立检索清单
GeoJSON detail事件附属产品及其下载链接定位 finite-fault 产品
.fsp有限断层几何、子断层滑移参数（以具体文件头定义为准）滑移模型转位移计算
.csv manifest事件、文件、来源及下载状态核查版本、避免重复

2. FDSN/ComCat API 的两级请求

第一级使用 USGS FDSN Event Web Service，按条件返回 GeoJSON 事件列表；第二级读取每个事件的 properties.detail，在 properties.products 中寻找 finite-fault 模型。一个事件可能没有此类产品，也可能有多个来源或版本。USGS 官方的 GeoJSON Detail 结构说明可作为字段依据。

原始项目在北太平洋采用的区域边界为纬度31.709°–66.399°N、经度125.859°–253.125°E。为处理跨180°经线的查询，程序将经度拆为 125.859…180 和 −180…−106.875 两段，合并后按事件 ID 去重。

% 原始流程的核心：查询事件列表
api = 'https://earthquake.usgs.gov/fdsnws/event/1/query';
opts = weboptions('Timeout',90,'ContentType','json');
catalog = webread(api,'format','geojson', ...
    'starttime','2005-01-01', 'endtime','2025-01-01', ...
    'minmagnitude',6,'eventtype','earthquake', ...
    'minlatitude',31.709,'maxlatitude',66.399, ...
    'minlongitude',125.859,'maxlongitude',180, ...
    'limit',20000,opts);

% catalog.features 包含事件 ID、震级、发生时间及 detail URL。
% 注意这只是经度分区之一；完整脚本还查询 -180 至 -106.875。
接口限制：USGS FDSN 单次查询最多返回20,000条事件。原脚本直接设置 limit=20000，没有实现自动分页；如果扩大区域、降低震级门槛或延长时间段，应按时间窗拆分或使用 offset 分页，不能把单页结果视为完整目录。

3. MATLAB 代码：原项目中的两个下载函数

本次专栏依据已有的 P13_download_USGS_FSP.m 与 P13_download_USGS_FSP_M6.m 编写。两者都执行地震目录查询、有限断层产品检索、FSP文件下载、断点式复用既有文件和错误日志记录，本身并不计算地震位移。

脚本实际查询设置说明
P13_download_USGS_FSP.mM≥7；2005-01-01 至 2024-12-01（结束界限）较高震级筛选；不覆盖2024年12月
P13_download_USGS_FSP_M6.mM≥6；2005-01-01 至 2025-01-01（结束界限）覆盖2005–2024完整日历期；下载机会更多

如果要覆盖2005–2024年全部月份并检索M≥6事件，优先采用第二个脚本，并修改 root 为本机研究目录。运行方式：

% 运行既有脚本，需联网（示例：M≥6）
addpath('/path/to/your/scripts');
SUMMARY = P13_download_USGS_FSP_M6();
disp(SUMMARY)

% 注意：修改脚本开头的 root 以适配本机目录。
% 文件由脚本保存到 data/raw/earthquake/USGS_FSP_2005_2024/

脚本依赖MATLAB的 webread、websave、weboptions、jsondecode 等能力，实际网络请求需要本机联网。不要求额外第三方工具箱；但下载成功取决于接口响应、文件链接是否仍可访问以及本机的权限设置。

4. 数据输出及可追溯清单

NorthPacific_SeaLevel/
└── data/raw/earthquake/USGS_FSP_2005_2024/
    ├── all_events.csv              # 搜索到的地震事件
    ├── fsp_files.csv               # FSP URL、来源及本地路径
    ├── errors.csv                  # 下载失败日志（有错误时）
    ├── USGS_FSP_download_summary.mat
    └── fsp/
        └── <event_id>/
            ├── p01_<source>_<model>.fsp
            └── ...

fsp_files.csv 记录 event_id、date_utc、magnitude、product_source、source_url、local_file、file_bytes 和 status 等字段。下载器会重试请求；overwrite=false 时非空的已有文件通常不会重新下载。文件未生成时（例如无错误的任务）可能没有 errors.csv。

5. FSP 下载后的必要检查

  1. 真实性：检查文件非空、不是HTML报错页，且有符合FSP规范的断层参数。
  2. 元数据：记录事件 ID、模型发布时间、提供单位、版本，以及事件详情页网址；同一事件不同模型不可误认为不同地震。
  3. 时间与震级：震级检索条件是USGS目录的 mag 字段，不保证所有记录都为Mw。
  4. 几何定义：确认 LAT/LON 是子断层顶部中心、底部中心还是质心；核对 DEPTH、STRIKE、DIP、RAKE、SLIP 的单位和符号。
  5. 可计算性：FSP下载成功不代表可直接送入Okada；不同产品的字段安排、注释行与参考点约定可能不同，需要逐个解析、转换并检查。

6. 与 Okada 地震位错计算如何连接？

本项目的后续处理由FSP解析/转换程序（如 P34_convert_one_USGS_FSP）与 okada85.m 等函数完成。对于第 i 个子断层，先将几何和滑移投影到局部东、北坐标系，确认断层质心深度，再计算三维位移；弹性线性近似下叠加各子断层结果：

u_E(x,y) = Σᵢ u_E,ᵢ(x,y) u_N(x,y) = Σᵢ u_N,ᵢ(x,y) u_Z(x,y) = Σᵢ u_Z,ᵢ(x,y) 区域平均同震抬升 = Σⱼ Aⱼ Mⱼ u_Z,ⱼ / Σⱼ Aⱼ Mⱼ

注意 okada85.m 函数约定断层深度是矩形断层质心深度，而FSP模型可能以子断层顶部深度表示，必须转换。相关理论、实际函数参数及示例请参阅本站 Okada 位错模型技术专栏。

北太平洋项目特别提醒：先前的 USGS 三月方案包含2011年3月多个事件，而Wei与Fujii–Satake方案仅为3月11日主震。若用这些结果计算“不同主震模型的标准差”，应先统一地震事件集合；否则只是不同计算方案之间的离散度。

7. 原脚本的已知问题、边界与改进建议

这里区分实际执行的查询条件与保存到MAT结构中的汇总字符串。在 P13_download_USGS_FSP_M6.m 中，查询实际使用M≥6、结束界限2025-01-01，但原始 SUMMARY 错写为M≥7与2024-12-01。应修正这些元数据，以免后续研究记录发生误读：

% 原 M6 下载器的汇总元数据存在不一致：
% 实际查询：2005-01-01 <= t < 2025-01-01, M >= 6
% 汇总字段原写成 end_exclusive_utc='2024-12-01', min_magnitude=7
% 建议修改为：
SUMMARY.end_exclusive_utc = '2025-01-01';
SUMMARY.min_magnitude = 6.0;
% 只修正汇总值；实际目录查询不因汇总字段变化而改变。

脚本还应改进：超过20,000事件时自动分页、记录远程产品更新时间或校验值、下载前后对同名文件进行去重比较，并为网络异常提供更易恢复的重试日志。使用者不应假定“USGS所有M≥6地震都有FSP”；USGS有限断层产品更常见于大型地震，其具体覆盖由产品发布情况决定。

8. 官方出处、软件与引用

  1. USGS FDSN Event Web Service：地震目录检索参数、查询及分页规则。
  2. USGS GeoJSON Detail Format：单事件 products 与资源链接结构。
  3. USGS Finite Faults：有限断层模型内容、FSP数据产品说明及相关文献。
  4. USGS ComCat Data Access：目录访问及查询接口。
  5. Okada, Y. (1985). Surface deformation due to shear and tensile faults in a half-space. Bulletin of the Seismological Society of America, 75(4), 1135–1154. 用于后续位错解析计算，并非USGS下载脚本的出处。

来源与复现说明：本文所述P13系列函数是研究项目的MATLAB自动下载脚本，而非USGS发布的软件。USGS负责提供地震目录及有限断层数据产品。本文没有远程批量下载、未统计事件数，也未声称所有潜在模型均可访问。投稿时应按实际选用模型记录其提供者及版本。
