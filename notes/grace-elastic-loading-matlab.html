1. 研究问题与理论背景

GNSS 观测的季节性地表位移可部分归因于陆地水储量变化引起的弹性负荷响应。GRACE/GRACE-FO 提供大尺度时变重力场信息，可据此估计地表质量负荷变化，再使用地球弹性响应 Green 函数计算任意测站的水平和垂向位移。

在弹性、线性响应近似下，位移可以形式化表示为负荷分布与相应 Green 函数的球面积分：

\[u_\alpha(\mathbf{x},t)=\int_{\Omega}G_\alpha(\mathbf{x},\mathbf{x}')\,\Delta\sigma(\mathbf{x}',t)\,\mathrm{d}A',\qquad \alpha\in\{E,N,U\}.\]

其中 \(\Delta\sigma\) 是面密度负荷变化；\(G_\alpha\) 分别为东西、南北、垂直方向的位移 Green 函数。具体积分实现、负荷单位及 Green 函数的归一化须与原始软件保持一致。

4. 计算流程与 Green 函数

  1. 准备地表负荷数据和 GNSS/计算网格位置。
  2. 使用 extraction_grace_area.m 选择研究区域。原文说明该脚本会建立 grace_extract 文件夹。
  3. 按程序提示决定是否计算 Green 函数；选择 y 时，原文报告会生成 green_functions_horizontal.mat 和 green_functions_vertical.mat。
  4. 调用程序中的 main.m 执行位移计算；参数顺序须参照当前下载的源码或原文截图。
  5. 检查网格与 GNSS 测站输出，并与观测的弹性负荷位移或独立模型比较。

5. MATLAB 检查代码示例

下面是本文新增的辅助检查脚本，用于确认软件路径、查看输入数据结构和输出目录；不是 CSDN 原文中 main.m 的源码或调用实例。

% Exploratory checks only — NOT a replacement for main.m
clear; clc;
which main -all
which extraction_grace_area -all

% Example: inspect a 3-column load text file after replacing filename
loadFile = 'your_grace_load.txt';
if isfile(loadFile)
    A = readmatrix(loadFile);
    assert(size(A,2) >= 3, 'Expected lon, lat, value columns');
    fprintf('Rows: %d | Longitude range: %.3f to %.3f\n', ...
        size(A,1), min(A(:,1)), max(A(:,1)));
else
    fprintf('Replace loadFile with an actual GRACE input file.\n');
end

for d = {'grace_extract','disp_zone','disp_gps'}
    fprintf('%s exists: %d\n', d{1}, isfolder(d{1}));
end

检查脚本不会创建 GRACE 数据，也不会执行弹性位移卷积。

原始 CSDN 示例仅展示一个 GNSS 台站（LHAZ）的三维位移。进行多站或区域分析时，应先在一两个站点验证响应符号、量级以及时间处理。

7. 适用范围与注意事项

  • 该方法模拟弹性响应，不等价于黏弹性松弛或 GIA；不同地球模型将导致不同响应。
  • GRACE 的粗分辨率、陆海泄漏、滤波和 mascon/SH 处理会影响负荷场。
  • 时间序列需要统一月份、参考历元及单位；比较 GRACE 与 GNSS 时尤其要避免任意插值缺测月份。
  • 地表水平位移依赖 Green 函数方向约定；将模型与 GNSS ENU 比较前需核对坐标系统。
  • 本文未执行原程序或复现数值结果，不能据此声称软件在当前 MATLAB 版本中已经通过测试。
