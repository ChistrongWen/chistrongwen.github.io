Scientific notes

The geographic basemap shows land and ocean boundaries only. Caron et al. (2018) model values are loaded from the bundled CSV files. The visualization displays the original 1° grid values as continuous raster cells without interpolation. Gravity values retain the original source units (mm/yr).

NASA/JPL GIA reference ↗
Caron et al. (2018) ↗
Data format: Longitude −180 to 180° (0–360° also accepted), latitude −90 to 90°, value in the units you specify. Blank or malformed rows are skipped. The original 1°×1° source values are preserved in the downloadable CSV files, while the globe displays the 1° grid as a texture without subsampling. The selected model field is not dynamically time-varying.
